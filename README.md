# 3D都市モデルを利用した避難所可視化

### 目的
このアプリケーションは、災害時における**避難所の位置をWeb上の3D地図に直感的に表示する**ことを目的としたものです。ユーザーは都市のリアルな3D景観の中で、避難所の位置と名称を視覚的に確認できます。

災害時は停電や通信混雑、視界不良、心理的ストレスなどにより、平面地図では現在地や進行方向、距離感、地形差の把握が難しくなりがちです。

そこで、**3D都市モデル（PLATEAU）と避難所データが公開されている横浜市全域を対象地域に設定**し、立体的な地図で避難所の位置を表示するアプリケーションに取り組みました。

### 使用技術
- TypeScript (型付き言語)
- Vue 3 (フレームワーク)
- CesiumJS (ライブラリ)
- Vite (ビルドツール)
- 開発支援ツール
    - Gemini (チャット)：エラーの原因分析、解決策の提案、コメント付与
    - GitHub Copilot (コード補完)

### 使用データ
- [3D都市モデル（PLATEAU / CityGML）](https://www.geospatial.jp/ckan/dataset/plateau-14100-yokohama-city-2020)
    
- [横浜市オープンデータ（避難所位置情報GeoJSON）](https://data.city.yokohama.lg.jp/dataset/somu_data)

### 主な実装機能

- 都市全域3D表示と区単位オンデマンド読込
- スマートローディング：視点高度に応じてデータ量を制御
- 各避難所の位置にアイコンと名称ラベルを表示
- 避難所のピン＋名称ラベル、クリックで詳細（住所等）
- カメラ操作（移動、回転、チルト）
